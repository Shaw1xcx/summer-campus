# 讨论与思考

## 一、IC 加权回测的未来信息泄露问题

### 问题描述

任务原文要求："使用当日各因子值与次日收益率计算的 IC 对因子进行加权产生信号"。这存在典型的前视偏差（look-ahead bias）：

- 当日因子值已知，但**次日收益率在决策时未知**
- 用未知的次日收益率计算 IC 来加权当日因子值，逻辑上不成立

### 解决方案

本次实现采用的修正方案：

1. **使用滚动历史 IC**：用过去 20 个交易日的 IC 均值作为权重
2. **避免使用未来数据**：确保决策时刻只需用到已知信息

### 进一步讨论

**IC 不稳定性问题**：IC 在时间序列上波动较大，可能正负交替，直接用滚动 IC 加权仍有以下问题：

- 某个因子过去 20 天 IC 为负，但未来可能转为正
- 建议使用 **EMA 平滑**（指数加权移动平均）替代简单均值
- 或使用 **ICIR**（IC / 标准差）替代 IC 作为权重，惩罚 IC 波动大的因子

**相关性陷阱**：4 个因子之间可能存在共线性，导致信号被重复计算。建议：
- 先用 PCA 或正交化处理因子
- 或在加权前对因子做去相关性处理

## 二、收盘价调仓 vs 开盘价调仓

### 结果差异

| 调仓方式 | 累计收益 | 夏普 |
|----------|----------|------|
| 收盘价 | +142.1% | 3.42 |
| 开盘价 | +12.7% | 1.17 |

### 为什么差距这么大？

**收盘价调仓存在隐性前视偏差**：

- 因子信号基于当日收盘价计算
- 调仓也使用当日收盘价
- 信号和交易价格是同一时刻，实际上无法实现（信号需要时间计算）

**开盘价调仓更真实**：

- 用前一日收盘价计算信号
- 次日开盘价执行交易
- 存在隔夜跳空风险，更贴近实际交易场景

### 实际交易建议

- 使用 **TWAP/VWAP** 算法拆单，减少冲击成本
- 考虑 **涨跌停限制**，无法买入的股票应有替代方案
- 加入 **流动性筛选**（如剔除日均成交额低于 100 万的股票）

## 三、LSTM 模型的局限性分析

### 为什么涨方向召回率低？

| 类别 | 样本占比 | 模型表现 |
|------|----------|----------|
| 下跌 | 29% | 召回率 29-40% |
| 持平 | 44% | 召回率 74-82% |
| 上涨 | 27% | 召回率 12-17% |

模型倾向于预测"持平"和"下跌"，因为：

1. **类别不平衡**：持平样本最多（44%），模型学习到了"偷懒"策略
2. **信号弱**：分钟级别的股价涨跌接近随机游走，预测难度大
3. **特征不足**：仅使用量价特征，缺少市场情绪、资金流向等信息

### 改进方向

#### 1. 损失函数优化
```python
# 使用加权交叉熵，给少数类更高权重
class_weights = [1.0, 0.5, 2.0]  # 对上涨类加权
criterion = nn.CrossEntropyLoss(weight=torch.tensor(class_weights))
```

#### 2. 引入更多特征
- 订单簿不平衡度（bid/ask 比例）
- 大单追踪（大额成交的方向）
- 跨股票相关性（同板块/同行业的联动）
- 时间特征（日内第几分钟、星期几）

#### 3. 模型改进
- 使用 **Transformer** 替代 LSTM，捕捉更长距离的依赖
- 添加 **Attention 机制**，关注关键时间点
- 使用 **多任务学习**，同时预测涨跌方向和幅度

#### 4. 采样策略
- 对训练集做 **SMOTE** 或过采样，平衡各类别
- 使用 **Focal Loss** 降低易分类样本的权重

## 四、因子有效性的深层思考

### 为什么所有 IC 均为负？

| 因子 | IC 均值 | 经济含义 |
|------|---------|----------|
| 成交额标准差对数 | -0.078 | 高成交额波动 → 低未来收益 |
| 波动率 | -0.058 | 高波动 → 低收益（低波动异象） |
| 买卖不平衡 | -0.040 | 主动买多未必是好事 |
| 动量 | -0.027 | 短期反转效应 |

所有因子 IC 为负，说明这些因子捕捉的是**风险溢价的反面**或**短期反转效应**：

- 高波动率通常对应高风险，但由于**低波动异象**，高风险不一定带来高收益
- 成交额异常波动可能意味着信息不对称或庄家出货
- 动量因子为负，说明在部分时段存在**短期反转**

### 样本外风险

本次回测在 302 个交易日内进行，结果可能受以下因素影响：

1. **样本期偏差**：2025-2026 年可能有特定的市场风格
2. **过拟合**：因子参数（窗口大小、组数）是固定的，需要交叉验证
3. **幸存者偏差**：300 只股票是随机抽取的，但可能排除了退市股票

## 五、数据规模与性能优化

### 处理 2.3 亿条记录的策略

1. **逐日处理**：每天读取 → 聚合 → 释放内存，避免全量加载
2. **Polars 替代 Pandas**：Polars 使用 Arrow 列式存储，比 Pandas 快 5-10 倍
3. **先保存再读取**：降采样结果保存为 CSV，后续分析直接读取，避免重复计算
4. **采样策略**：LSTM 训练时使用 10-20 只股票的子集，减少计算量

### 可进一步优化的点

- 使用 **Parquet** 格式替代 CSV 存储降采样结果，读取速度更快
- 使用 **GPU 训练** LSTM（当前仅使用 CPU）
- 使用 **Dask** 或 **Ray** 做分布式处理
